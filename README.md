# X-Zeta

My own version of Cheat Engine for Browsers.

## Existing Features:-

- WireFrame
- Speed Hack

## Developing Features:-

- Wasm memory Editing

More features will be added in future updates.

### How to use it?

Go to tampermonkey and put @require https://raw.githubusercontent.com/3lectr0Ninja/X-Zeta/refs/heads/main/X-Zeta.js

Example:-

```js
// ==UserScript==
// @name         X-Zeta
// @match        https://example.com/*
// @require      https://raw.githubusercontent.com/3lectr0Ninja/X-Zeta/refs/heads/main/X-Zeta.js
// @run-at       document-start
// ==/UserScript==
```
